# HIDAYA ONE — Web Dashboard (Angular 22)

Production dashboard frontend for Hidaya One Islamic Shorts Automation Platform.

## Technology Stack
- Angular 22.2.6 (Standalone Architecture, Angular Signals, RxJS)
- Tailwind CSS 4
- TypeScript 5.9
- Deep emerald, dark teal, and holographic gold design system

## Commands
```bash
npm install
npm start        # Starts local development server on http://localhost:4200
npm run build    # Compiles production distribution to dist/hidaya-one-web
```
