# HIDAYA ONE — Agent Core (Google ADK TypeScript)

Core intelligence runtime orchestrating 13 specialist agents and the 23-point deterministic religious verification gate.

## Commands
```bash
npm install
npm run test:gate # Runs 23 deterministic religious verification gate tests
npm run typecheck # Verifies TypeScript compilation
npm run adk:run   # Executes agent interactive session
npm run adk:web   # Launches ADK web development UI
```
