# HIDAYA ONE — Backend-for-Frontend API (Node.js)

The BFF layer for the Hidaya One Angular dashboard. Exposes typed endpoints validating requests via Zod and delegates tasks to the private ADK agent runtime via Google Cloud ID token authentication.

## Commands
```bash
npm install
npm run dev      # Starts API on http://localhost:3000
npm run build    # Compiles TypeScript to dist/
npm run typecheck # Verifies TypeScript types
```
